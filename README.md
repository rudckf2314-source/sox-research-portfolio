# 워크포워드 머신러닝을 활용한 필라델피아 반도체 지수 방향 예측과 변수군별 추가 예측력 평가

SOX의 일별 수익률을 공통 대상으로 삼아 세 가지 과제를 평가했다. 상승·비상승 방향 예측은 [최종 논문](논문/워크포워드_머신러닝을_활용한_필라델피아_반도체_지수_방향_예측과_변수군별_추가_예측력_평가.pdf)의 본 분석이다. 4등급 분류와 일별 수익률 회귀는 같은 월별 입력과 평가기간을 사용하는 보조 분석이다. 세 과제의 성능은 [통합 결과표](재현결과/전체_조합의_주요_예측_성과.csv)에서 확인할 수 있다.

## 연구가 진행된 순서

1. 원천별 관측일과 사용 가능일을 미국 동부시간 09시 기준으로 정렬했다. 예측 대상은 SOX의 당일 종가 대 전일 종가 수익률이다.
2. 2016·2018·2020년 탐색에서 256개 조합을 비교하고 공통 16개를 선택했다. 2021~2023년으로 사전선정 설정을 확정했다. 이 경로에서는 당시 저장된 탐색·확인 성능표로 조합 선택을 재계산한다.
3. 2011-02-03부터 각 직전 월까지 누적 학습했다. 결측 중앙값·표준화·PCA·중복 변수 제거는 월별 학습 정보로 결정했다. 보존 배열에는 그때 실제 모형에 들어간 변환값과 월별 열 구성이 있다.
4. 2024-01-02부터 2026-10-23까지 34개월 706거래일을 평가했다. 2026년 10월 추가 12일에는 9월 말까지 학습한 모형을 유지했다.
5. 상승·비상승 방향 예측, 4등급 분류, 수익률 회귀를 같은 날짜에서 계산했다. 이진은 상승과 비상승, 4등급은 전년도 절대 일별 수익률 중앙값 기준, 회귀는 일별 수익률 자체다. 구간별 전체 최고 모형은 평가기간 관측치다.
6. 같은 알고리즘에서 변수군 추가효과를 비교했다. 20거래일 순환 블록 5,000회로 구간·근사 p값을 계산하고, 보조연구 포함 Holm90과 최종 이진 Holm30을 구분했다. 변수중요도는 고정 모형에서 월 내 한 열을 5회 섞어 로그손실 변화를 측정했다. SOXQ 모의투자은 별도 보조 분석이다.

## 실행

기존 환경과 같은 Python 3.13.16과 [고정 버전 목록](requirements.txt)을 사용한다. 설치 후 다음 명령으로 실행한다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py --mode key
```

| 모드 | 재현 범위 |
|---|---|
| `--mode replay` | 저장 예측에서 16개 조합 선정, 성능, 90개 비교·Holm30, SOXQ 결과 재계산 |
| `--mode key` | 위 계산과 34개월 주요 5개 설정 재학습, 저장 확률·수익률과 대조, 3개 분류 설정의 월내 중요도 재계산 |
| `--mode full` | 위 계산과 16개 조합 × 6개 알고리즘 × 3개 목표의 월별 재학습 및 저장 예측 대조 |

출력은 `재현결과/`에 저장한다. 다른 실행을 구분할 때는 `--out 재현결과/별도이름`을 지정한다.

## 폴더 구성과 재현 경계

- `데이터/월별입력/`는 실제 월별 학습·평가 입력과 모형별 열이다. `데이터/예측정답.csv`는 학습과 채점용 정답이다.
- `데이터/원천자료/`는 논문에 정리한 원천자료, 예측시점 정렬 변수, 변수 사전과 공개시점 근거다.
- `기준자료/`는 검산할 저장 예측·검정·중요도·모의 적용 결과와 선택 기록이다.
- `run.py`, `estimators.py`, `simulation.py`가 새 경로에서 실행하는 코드다.
- `원본코드/`는 선정·정렬·시점 검증·재학습·분석 당시의 핵심 코드 발췌 보존본이다. 기존 폴더 구조와 경로를 기록하고 있다.
- `파일_출처와_해시.json`은 복사한 파일의 출처와 SHA-256이다.

이 패키지의 실행 시작점은 보존된 월별 변환 입력과 탐색 성능표다. 원천 사이트의 재수집이나 초기 256조합 전부의 재학습은 별도 단계다. 원래 정렬에 사용한 공개 유예 가정과 자료 수정 이력의 한계도 함께 적용된다.

## 원천자료 대조와 보완 결과

- 원본 논문 연구 폴더의 RAW 299개와 변수 데이터 4개를 모두 파일별 SHA-256으로 확인했다. 원본 정답, 월별 모형 입력 104개와 가용 시점 근거도 대조했다. [데이터 대조 결과](데이터/원천자료/원본_데이터_대조결과.json)
- 항상 상승의 Macro-F1·균형 정확도와 연도별 성과를 함께 출력한다. 이진 방향과 회귀의 [20일 블록 신뢰구간](재현결과/모형별_성능차이_20일_블록신뢰구간.csv)을 다시 계산해 원본과 대조한다.
- [최종 PDF의 그림 1~3](논문/그림/)은 PDF에서 추출해 보존했다. [재생성한 그림](재현결과/그림/)은 검증된 결과로 그린 것으로, 원본 배치와 표기는 다를 수 있다. replay의 그림 2는 보존된 중요도를, key·full은 재계산한 중요도를 사용한다.
- [회귀 변수중요도](기준자료/회귀_변수중요도.csv)는 원본 706거래일 결과를 보존했으며 현재 실행에서는 다시 추정하지 않는다.
