# 최종 논문 증거자료

원본 연구 폴더의 파일 539개를 대조했다. 61개를 원본 그대로 추가했고, 478개는 SHA-256이 일치하는 보존 파일에 연결했다. [원본 증거자료 대조표](원본_증거자료_대조표.csv)의 보존 경로는 SOX_RESEARCH 루트 기준이다.

- [핵심근거](핵심근거/)에는 원본의 등급 분포, 신뢰구간, 월별 성능과 최종 수치 대조 기록이 있다.
- [전체실험결과](전체실험결과/)에는 원본 전체결과 엑셀, 혼동행렬·등급별 지표, 구간별 성능과 예측 봉인·검증 기록이 있다.
- [원천자료](../데이터/원천자료/)와 [재현결과](../재현결과/)는 루트에서 바로 확인할 수 있다.
- 원본 문서와 메타데이터의 내부 링크 및 경로는 당시 기록이다. 현재 위치는 대조표를 사용한다.
